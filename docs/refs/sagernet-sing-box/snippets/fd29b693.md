Replace the deprecated store_rdrc field with store_dns in the experimental cache_file configuration to persist the full DNS cache.

```json
{
  "experimental": {
    "cache_file": {
      "enabled": true,
      "store_rdrc": true
    }
  }
}
```

```json
{
  "experimental": {
    "cache_file": {
      "enabled": true,
      "store_dns": true
    }
  }
}
```
