The `query_type` field in DNS rules now also applies when the DNS rule is matched from an internal domain resolution that does not target a specific DNS server. Previously, this field only evaluated DNS queries received from a client. When a DNS rule references a rule-set with `query_type`, it becomes incompatible with legacy Address Filter Fields, the legacy `strategy` DNS rule action option, and the legacy `rule_set_ip_cidr_accept_empty` DNS rule item.
