The legacy DNS server format had a `detour` field for specifying the outbound to connect to the DNS server. This legacy format was deprecated in sing-box 1.12.0 and removed in 1.14.0. The new DNS server format uses Dial Fields (DialerOptions) instead, which includes its own `detour` field. The documentation notes that the new server 'uses dialer just like outbound, which is equivalent to using an empty direct outbound by default.'

```json
{
  "dns": {
    "servers": [
      {
        "tag": "",
        "address": "",
        "address_resolver": "",
        "address_strategy": "",
        "strategy": "",
        "detour": "",
        "client_subnet": ""
      }
    ]
  }
}
```
