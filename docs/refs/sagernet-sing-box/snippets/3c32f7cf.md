This section describes how to compile a JSON rule set file into a binary rule set file using the sing-box command-line interface.

```APIDOC
## Compile Rule Set

### Description
Use the `sing-box rule-set compile` command to convert a JSON rule set file into a binary `.srs` file.

### Method
Command Line Tool

### Endpoint
N/A (Command Line)

### Parameters
#### Command Line Arguments
- **`--output <file-name>.srs`** (string) - Optional - Specifies the output file name for the compiled binary rule set.
- **`<file-name>.json`** (string) - Required - The input JSON file containing the rule set configuration.

### Request Example
```bash
sing-box rule-set compile --output my_rules.srs my_rules.json
```

### Response
#### Success Response
Compilation is successful if no errors are reported. A binary `.srs` file is generated.

#### Response Example
(No specific output on success, but the file is created.)
