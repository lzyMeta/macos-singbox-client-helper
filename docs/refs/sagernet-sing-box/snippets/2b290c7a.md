Since version 1.12.0, sing-box introduced differences in how TCP DNS servers operate compared to the legacy implementation. The old server defaulted to using the default outbound unless a detour was specified. In contrast, the new implementation uses a dialer, similar to how outbound connections are handled, effectively using an empty direct outbound by default. Furthermore, the new TCP server utilizes `domain_resolver` and `domain_strategy` within the Dial Fields for resolving domain names, whereas the old server relied on `address_resolver` and `address_strategy`.
