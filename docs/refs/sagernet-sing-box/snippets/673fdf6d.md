The RemoteRuleSet struct defines the configuration for a remote rule set (subscription). The `url` field is the subscription URL, `download_detour` (deprecated in 1.14) directly references an outbound tag, and `http_client` wraps DialerOptions to provide the outbound reference via its `detour` field. In version 1.12, `download_detour` was the primary mechanism.

```go
type RemoteRuleSet struct {
	URL            string             `json:"url"`
	InitialPath    string             `json:"initial_path,omitempty"`
	HTTPClient     *HTTPClientOptions `json:"http_client,omitempty"`
	UpdateInterval badoption.Duration `json:"update_interval,omitempty"`
	// Deprecated: use http_client instead
	DownloadDetour string `json:"download_detour,omitempty" reference:"outbound" schema:"omit"`
}
```
